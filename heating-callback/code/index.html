Heating callback landing page: code for GoHighLevel

This folder holds the complete code for the City & Suburban Heating & Cooling heating callback page. The finished page, exactly as a visitor from a Meta ad sees it, is at ../heating-callback/. It is designed for phones, and on a computer it shows as a centred phone-width column.

The code files

  • ghl-custom-code-light.txt (45 KB) is the recommended version. It is the whole page in one block of HTML, CSS and JavaScript, with the images loaded from this site.
  • ghl-custom-code-full.txt (262 KB) is the same page with every image embedded in the code, so it depends on nothing else. Use it only if the code element accepts a file this large.

The .html files beside them hold identical code; the .txt copies exist so a browser shows the code as text instead of running it.

How to build it in GoHighLevel

  1. Create a blank page in the funnel or website and remove the default header and footer.
  2. Add one full-width section with zero padding on the section, row and column.
  3. Add a Custom JS/HTML element, paste the entire contents of the light code file, and save.
  4. Set the page title to "Heating Repair Callback | City & Suburban Heating & Cooling" and add <meta name="robots" content="noindex"> to the page's header code.
  5. Make sure the Meta Pixel base code is on the page.

The code must be pasted as it is, not rebuilt from native GoHighLevel elements. The two-step form, the back-button behaviour, the Meta Lead event and the thank-you screen all run from the script inside it.

Connecting the form

The form sends each lead to a GoHighLevel workflow with an Inbound Webhook trigger. Paste that workflow's webhook URL between the quotes after webhookUrl: in the CSQ_CONFIG block at the top of the code. Until then the page works fully but sends nothing. Each lead is sent twice: once after Step 1 with form_stage set to step_1_contact, and again on the final submit with step_2_complete and the address.
